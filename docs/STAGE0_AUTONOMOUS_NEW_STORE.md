# Stage0 陌生場域無互動建置要求

2026-09-17。使用者要求未來陌生 StudioA 場域可自行建置，不必每台相機都由使用者或
對話中的 AI 先看圖、選點、調參。**這是正式驗收目標，目前尚未實作完成或通過驗收。**
本文件調整接續工作的優先順序，不宣稱已有完整自動建置入口。

## 階段責任

沿用 [Stage 能力定義](STUDIOA_CAPABILITY_AUDIT.md)：Stage0 提供相機／鏡頭模型、
尺度狀態、地面及共享座標、品質和來源版本；Stage1 負責場景分類、物件實例、形狀及支承。
Stage0 可調用固定版本的感知模型取得地面與結構候選，但不能將感知結果視為幾何真值。
Stage2–4 只使用對應能力已通過的輸出；例如尺度未確定時，不輸出可信公尺距離。

## 允許的輸入與禁止的依賴

正常入口只需要新場域影像／影片、camera/store 識別與可取得的攝影機元資料。
若系統已有相機標定、已知安裝尺度、平面圖或可靠尺寸來源，可以自動讀取並記錄其依據。
沒有尺度來源時，允許建立比例幾何，但必須標示尺度未定，不能由模型信心變成實測公尺。

正常流程不得依賴以下事先為目標相機製作的檔案或互動：

- 對話 AI 或使用者手選影格、線段、角點、遮罩、ROI、櫃體尺寸、房間方向。
- 先前 commissioning 的相機、地板區域、深度快取、支撐遮罩或物件 ID。
- 按店名／camera ID 寫入例外方向、固定櫃子位置或測試結果專用參數。
- 每次建置後等待對話審圖才決定是否可用。

以上資料可保留作開發診斷或離線評估參考，不能算作無互動新店輸入。
程式自動產生的相機參數、實例、控制候選和快取則是允許的中間產物。

## 接續實作順序

1. **自動取得觀測。** 從原始解析度影片選取清晰、結構穩定且遮擋少的影格；
   由影像證據與固定感知模型提出線／曲線、角點和表面關係。弱邊、陰影、反射及
   動態遮擋可被排除；記錄取捨依據。不得內建高雄點位或逐鏡頭 ROI。
2. **自動驗證與恢復。** 將同一實體線的多影格觀測分成同一組，避免同一條線
   一面用於擬合、一面當成獨立驗證。凍結分組後比較相機／畸變假設；
   證據不足時按固定策略換時段、換影格或使用同店重疊鏡頭，重試上限須明確。
   固定 CCTV 的不同時間影格只提供去遮擋及重複性，不增加三角測量視差。
3. **形成有能力界線的空間基礎。** 校正、尺度與跨鏡頭對齊分別判定；
   在隔離候選中建立深度／區域及來源版本，再交由既有 Stage1 建模與最終 GLB 回投影。
   不因任何一個分數通過就默認其他能力完成。
4. **封存後做整店留出。** 固定程式、權重、模型提示、閾值、候選選擇及重試策略，
   從全新工作目錄只給目標店原始輸入，自動跑完。程式可依固定方法使用輸入影像
   估計該相機參數，但不能讀取評估參考標籤或在看到答案後修改方法。

既有高雄候選重建可作第 3 項的開發回歸，但接續研發的優先項改為第 1、2 項，
避免持續增加每台相機專用的選點與修櫃流程。重用既有校正器、投影、來源及建模器，
不再建立另一套展示用 3D 流程。

## 自動輸出與驗收

設計上必須同時提供運行狀態和能力狀態，不能只有「成功產生檔案」：

- 運行狀態：完成、部分完成、證據不足或執行失敗，並留下原因與可重播紀錄。
- 能力狀態：校正、相對幾何、公尺尺度、同店跨鏡頭對齊各自是否可用；每個場景物件
  也帶來源與未確定狀態。無法確定的區域不能自動補成已確認的完整實體。
- 品質：保留未用於擬合的結構／影格核對；最終幾何的投影誤差、接地／支承、碰撞及
  尺度來源分開記錄。AI 參考一致性不可冒稱現場幾何真值。

整店留出須報告全部測試店／相機的自動完成率、部分完成率、拒絕率、誤接受率、
有效幾何覆蓋率、誤差分布、耗時及運算成本。不能只報成功案例，也不能以全部拒絕
取得表面上的零錯誤。最低完成率等產品門檻需在封存測試前固定，現在不捏造已達標數字。

現有三店已多次用於開發；歷史留出分數可作回歸，不能再宣稱是未看過的新店盲測。
新的封存場域不得與訓練／開發共用相機或影像內容。改名已看過的相機不算新場域。

自動化的目標是無逐相機互動即可產生可信且有界線的結果，不保證任何單張影像都能
恢復完整、絕對公尺尺度的世界。缺少物理可觀測資訊時，系統應自動保留不確定性。
