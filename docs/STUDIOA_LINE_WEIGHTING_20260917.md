# Stage0 結構線等權修正與方向診斷

2026-09-17。接續[有界補觀測回歸](STUDIOA_STRUCTURAL_RETRY_20260917.md)。本輪重用凍結線組，
沒有重跑 SAM 3、增加影格或調整分組／8 px 驗收門檻。

## 確認並修正的問題

方向假設階段對每條線取等量樣本，但 `refine_structural_camera()` 原本直接加總所有
取樣點的 robust loss，導致取樣點數也成為整條線的權重。重複同一條線的全部取樣點
不增加新幾何資訊，卻會改變擬合結果，與避免重複計票的目的不一致。

新增合成反例：固定所有幾何與擬合／留出分組，只把一條帶有擾動的擬合線之全部
取樣點重複 7 次。舊實作測試失敗，畸變 k1 從約 -0.29588 變成 -0.28771。
修正後五個擬合參數在 1e-5 絕對容差內不變。

新目標為「先算每條線的平均 soft-L1 點成本，再加總各線」。權重作用於 loss 及其
一、二階導數，不是先縮小殘差，因此保留既有 2 px robust 轉折尺度。多初始值的
比較與 baseline 方位求解也使用同一個目標，全部只讀擬合線。
這修正的是取樣數造成的整線權重；並不證明不同線的量測精度相同，也不保證線內不均勻
取樣完全不影響幾何。所有原始點仍參與最終最大誤差檢查。

## 新增的必要診斷

既有校正報告的每條線增加 `direction_diagnostic`，固定已求得的相機參數，計算：

- 三個世界方向各自的最大 raw 像素誤差，以及哪些方向在既有門檻內。
- 同一鏡頭參數下，解除世界方向限制後的 ideal TLS 直線，再投影成 raw 曲線的最大誤差。
- 無法定義的替代方向記為 null 與原因，不讓附加診斷阻斷原本可計分的擬合。

TLS 最小化 ideal 平面的平方誤差，不是 raw 最大誤差的精確下界。這些數字只解釋
目前假設下的不一致，不能直接判定某條線是假邊、相機錯誤或真實物體不正交。
診斷在擬合後產生，不刪除線、不改方向、不改分組、不選擇另一個相機解。

方向不阻斷診斷。原有留出污染不改變擬合、已知幾何恢復及重試停止規則仍通過。
