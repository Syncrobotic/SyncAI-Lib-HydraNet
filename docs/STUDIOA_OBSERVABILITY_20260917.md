# StudioA 同店多視角可觀測性盤點

2026-09-17。研究方向檢查後的第一步：確認現有影片能支持哪些幾何問題，
再決定是否補資料。本輪只讀 GCS、盤點本機資料及執行開發篩選；未訓練、未部署相機校正。

**結論：已有同店可見重疊的影片，足以開始多視角開發實驗；尚不足以宣稱自動重建或
公尺尺度成立。優先解決跨鏡頭對應及鏡頭假設，現在不需要大量下載更多影片。**

## 已執行的篩選及結果

一次性分析程式位於 `runs/studioa_observability_20260917_v1/worker.py`，沒有新增正式
3D 工具。執行前凍結程式、角色清冊、46 個來源影片 SHA-256、抽影格策略及閾值。
原生 PNG 保留不改尺寸；僅特徵分析統一到寬 960，上下各排除 10%。

使用 SIFT、雙向 ratio 0.75、跨時段位移 ≤3 分析像素的穩定特徵，再以 F-RANSAC
篩選跨鏡頭對應。兩個時段都須有至少 12 個去重後內點、兩側凸包覆蓋率各至少 2%、
各至少佔 4 個 4×4 格子。RANSAC 閾值 3 分析像素、seed 17；未在看結果後放寬。
方法參考 [OpenCV 特徵匹配文件](https://docs.opencv.org/4.13.0/dc/dc3/tutorial_py_matcher.html)
及[對極幾何文件](https://docs.opencv.org/4.13.0/da/de9/tutorial_py_epipolar_geometry.html)。

這只是低成本開發篩選：輸入仍有未校正的鏡頭畸變，F 模型不保證適用；低解析度影格
放大也不增加資訊。跨時段篩選可能移除有用特徵；兩時段共享穩定特徵，不能當成兩組
完全獨立的驗證。H 內點數只供診斷，與去重後 F 內點數的計數方式不同。

**0 組通過不表示沒有重疊；全部拒絕時，負對照 0 通過也不能證明方法可用。**
本輪逐一看過三店聯絡表中的 23 個視角，台中 cam04／05／06 可見同一展示區的圓桌、
中央展示桌及盒裝商品牆。這組也已存在於既有 `map_anything_eval.py` 的 same-room
開發組。影像可見重疊與自動匹配失敗之間的差距，是下一個需要解決的問題。
重複包裝、低紋理表面、視角差及鏡頭畸變是待分離的原因，尚未證明各自影響量。

人工／對話 AI 的本輪審圖只作離線診斷，沒有將對應點、ROI、方向或尺寸輸入建置流程；
此組不能被列為自動發現的重疊圖，也不是未見店驗收。聯絡表統一縮圖比例，不能用來量測。

## 既有能力與下一個實驗

專案已有 `tools/commissioning/map_anything_eval.py`：intrinsics 支援 MapAnything、DA3、
VGGT；register 目前只有 MapAnything，並有跨城市負對照。歷史紀錄已指出模型會把
不同城市相機放成看似合理的相鄰位置，所以僅有姿態或 confidence 不足以接受場景。
本輪沒有重跑那些模型；本機未找到其預設歷史 `runs/mapany01` 結果，不能將文件中的
舊數字算成本輪實測。

現有入口讀取 commissioned plate／camera，未建置鏡頭還會沿用 fleet k1。
本機已有指定 MapAnything snapshot 目錄，但主 `.venv` 沒有 `mapanything`；
尚未確認權重完整性及 GPU 推論。因此不能直接執行舊入口後宣稱完成陌生店試驗。

接續沿用既有模型介面、投影與建模器，先完成一個有上限的開發實驗：

1. **固定輸入與假設。** 使用本輪台中 cam04／05／06 六張原生影格和固定跨店對照；
   在新輸出目錄記錄原始像素座標、模型與權重版本、轉換和資源上限。
   將既有入口對 commissioned 資料的依賴拆開；fleet k1 只可列為明示比較假設，不能作真值。
2. **先驗證對應。** 比較原始影像、明示鏡頭假設和自動模型對應；將有無時間穩定篩選、
   分析解析度等因素分開對照。預先固定試驗組合，不逐相機改閾值或補點。
   模型輸出的相機與深度必須能支持影像中的跨視角對應、覆蓋與循環一致性。
3. **再判定相對幾何。** 報告三視角連通性、非退化視差、未用於擬合的原始像素重投影
   誤差，以及換時段後的穩定性；分開報告成功／拒絕與跨店誤接受。
   時鐘、尺度及被遮蔽物件仍可未定，不能用人物平均身高冒充實測尺度。
4. **通過後接回現有 Stage1。** 在共享相對座標內建立物件實例，將同一份 GLB 回投影
   到三個 CCTV；核對圓桌、長桌、直立架的朝向、輪廓和支承。
   失敗時保留失敗診斷，不用新的展示工具掩蓋投影問題。

此開發組至少三視角已足夠問「能否建立可驗證的共享相對幾何」；先不擴到五台。
現有資料支持開始實驗，不代表一定能恢復完整場域。正式陌生店成功率、誤接受率與品質門檻
需在方法封存前訂定，額外店只能在來源與歷史使用核對後納入。
