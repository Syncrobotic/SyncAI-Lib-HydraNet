# Stage0 原始影格自動結構候選

2026-09-17。已實作不讀取目標相機既有校正、遮罩、深度或人工點位的候選產生器。
**這是陌生場域自動化的第一個元件，還不是自動校正或完成的 3D 世界。**

本文件保留第一版純影像觀測的實驗紀錄。後續 `--structure` 表面與方向流程及其
拒絕結果見 [Stage0 表面與條件方向假設](STUDIOA_STRUCTURE_AUTONOMY_20260917.md)。

## 入口與資料契約

```bash
.venv/bin/python tools/commissioning/structural_observe.py CAMERA_ID \
  /path/to/single-camera-frames --out /path/to/new-proposals.json
```

輸入為同一固定相機、檔名按時間排序的 JPG／PNG 目錄。camera ID 只作來源標籤，
沒有依店名或相機名稱選擇參數。此入口尚不負責影片解碼、跨鏡頭對齊或確認相機未移動。
輸出採獨立 `structural-edge-proposals-v1` 契約，不能當作既有校正器的 controls 檔。
CLI 成功退出代表完成候選抽取，能力狀態必須讀取 JSON。

實作位於 `src/syncai_bev3d/structural_observations.py`，沿用 commission extra 已宣告的
NumPy、SciPy、Pillow，不新增模型或依賴。處理步驟：

1. 按檔名順序均勻掃描最多 24 張影格，記錄未掃描項目；用解碼像素雜湊排除重複影像，
   避免同一內容不同壓縮檔案被計為多影格證據。
2. 將可用影格分成最多 6 組，各取縮圖梯度能量最高者。這只是簡單品質啟發式，
   尚未判定遮擋率，也不是經驗證的清晰度量測。
3. 在原始解析度計算梯度極大值，以受局部梯度方向限制的 Hough 投票提出窄走廊。
   沿走廊追蹤實際邊緣像素，允許局部二次曲線；檢查長度、取樣間隙及曲線殘差。
   每張最多檢查 180 個種子、保留 48 條候選，達上限會記錄 `budget_reached`。
4. 依原像素重疊、方向與距離建立候選軌跡。至少出現於 2 張、且達選取影格半數，
   才標記 `persistent`。同影格一對多、或經連鎖配對但彼此不一致的群組標為
   `ambiguous_match`；不足者為 `transient`。
5. 記錄選取依據、已掃描檔案 SHA-256、像素 SHA-256、原始尺寸、原像素點、設定、
   實作雜湊及依賴版本。選定來源在抽取前若已改變則拒絕；不覆蓋既有報告。

三種軌跡狀態都仍是候選。靜態陰影、反射、標語或相鄰物件可以形成持續邊緣，
影像座標接近也不證明同一實體線。全部 `axis=null`、`calibration_eligible=false`，
`physical_line_identity=unresolved`、`split=unassigned`。實體線歸屬未確定前不分配
擬合／留出集，避免同一條線的片段或多影格副本洩漏至兩側。

完整輸出在 `runs/studioa_autonomous_observations_20260917_v2/`；先凍結程式、設定及來源

三組影格均為原始 1920×1080。同一實體可能仍被分為多段，不能將軌跡數解讀為
正確結構數、幾何覆蓋率或模型精度。耗時只記錄此機器這次執行，未做吞吐量基準。
三台皆為 `status=partial`、`calibration_ready=false`、`deployment_ready=false`、
`scale_status=unknown`。沒有產生 camera.json、更新快取或替換 GLB。

開發檢視涵蓋 18 張候選疊圖（各相機六格 contact sheet）：門框、展示櫃立邊與桌緣
有可見候選；高雄的弱對比地板格線覆蓋不足，鄰近雙邊及遮擋會產生模糊群組。
此人工開發檢視沒有回饋逐鏡頭參數，也不是運行時的審核依賴。
疊圖只診斷原始影像候選，不是 3D 世界成品。

這三店已用於開發，結果不能當作陌生店盲測或無人建置成功率。

## 驗證與下一步

自動測試覆蓋彎曲邊緣的原像素定位、重複內容不增加證據、模糊／漂移配對拒絕、
camera ID 改名不改結果、來源變更拒絕、混合解析度拒絕、空白影像拒絕與報告不可覆寫。
新觀測測試及既有結構校正測試共 18 項通過；全專案 Ruff check／format 與新增檔案
型別檢查通過。完整 suite 為 **4,233 passed、12 skipped**，耗時 141.99 秒；
跳過項目需要 CUDA，完整結果記錄於本次 run 的 `pytest.log`。

接續工作為自動提供表面／結構語意與遮擋依據，補足弱地板邊、排除文字與反射候選，
再建立含鏡頭畸變的物理方向假設與整條實體線分組。必須在分組凍結後才接入既有
校正器作擬合及留出檢查。固定鏡頭跨時間只增加可見性與重複性，不增加三角測量視差；
沒有外部尺度來源時，不把結果宣稱為可信公尺世界。
