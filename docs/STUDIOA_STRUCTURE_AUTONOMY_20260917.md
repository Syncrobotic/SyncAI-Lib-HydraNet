# Stage0 表面、弱地板邊緣與條件方向假設

2026-09-17。接續 [原始影格自動觀測](STUDIOA_AUTOMATIC_OBSERVATIONS_20260917.md)，
同一個入口已加入固定模型的表面候選、地板內弱邊緣抽取、整線分組及方向檢查。
這些是可自動執行的候選與拒絕流程，尚未構成陌生場域的部署驗收。

```bash
HF_HUB_OFFLINE=1 TRANSFORMERS_OFFLINE=1 .venv/bin/python \
  tools/commissioning/structural_observe.py CAMERA_ID /path/to/raw-frames \
  --structure --device cpu --out /path/to/new-report.json
```

需要 `commission` 與 `annotate` extras，及現有 SAM 3 權重。離線環境須先具備固定 revision
的模型快取；正式入口的 camera ID 仍只用於來源標籤。`--structure` 為可選的較昂貴流程；
未指定時維持純影像觀測。輸出旁的 `.evidence/` 保存逐影格模型遮罩、雜湊、進度及
`groups.freeze.json`。已有輸出或 evidence 目錄會拒絕覆蓋。

## 自動產生的證據

`structural_surfaces.py` 重用專案的 SAM 3 wrapper，固定
`facebook/sam3@3c879f39826c281e95690f02c7821c4de09afae7`，
提示為 `floor/person/mirror/glass/poster`，score 與 mask 門檻均為 0.5。
同影格的 vision features 只算一次，記錄模型 revision、wrapper 雜湊、依賴版本及每個
遮罩對應的 raw 影格 SHA-256。模型只接收 RGB，不接收 camera ID、既有校正或手選 ROI。

地板遮罩向內縮，人物遮罩向外擴，另外排除模型提出的鏡面、玻璃與海報區。
原始候選若超過 10% 取樣點落入排除區，會保留在 rejected 列表並記錄原因。
在剩餘地板內，沿用同一個原始解析度梯度與曲線追蹤器，將梯度下限改為 0.003、
區內 quantile 改為 0.8；一般影像仍是 0.015／0.9。這是固定的表面別策略，沒有逐相機參數。
重建跨影格軌跡前會去除同影格重複候選，新增點仍是實際梯度極大值，不是模型畫出的格線。

這些遮罩是預測，不是幾何真值。漏掉的人物、陰影、反射及誤判表面仍可能影響候選，
不能宣稱已完整排除所有動態物體或假邊緣。

## 整線分組與驗證隔離

`structural_directions.py` 在允許的 division lens 範圍 `k1 ∈ [-0.6, 0]` 上作固定網格檢查。
可由共同曲線解釋的跨影格觀測與分離片段歸入同一候選線組；不一致或連鎖合併有歧義的
群組拒絕進入擬合。這是幾何等價候選，不是已確認的實體物件 ID。

在選擇相機參數之前，以線組 ID 的 SHA-256 固定約 1/4 為留出組，封存分組與輸入雜湊。
同組多影格或片段不會分到兩側。不能因留出不足或分數差而重新抽籤。每組按原始跨度
選擇一條代表觀測，避免重複影格乘增票數；點位仍交給原有校正器處理。

方向假設只使用擬合組：

1. 在各個 division lens 假設下，用地板線的交會估計兩組消失點，不以畫面斜率命名世界方向。
2. 在固定主點、正方形像素與兩個地面方向正交的條件下，由消失點約束焦距，推導地面法向
   與垂直方向，再檢查其餘候選線的支持。
3. 以擬合資料選擇假設後，才對留出組指派待檢查的方向。所有留出候選都參與檢查，
   不因誤差大就刪除；地板語意與垂直方向衝突也會拒絕。
4. 重用 `refine_structural_camera()` 的多初始值、邊界、條件數及原像素曲線誤差檢查。
   1920×1080 的誤差門檻是 8 px，與既有 960×540 的 4 px 按解析度等比例，不是放寬標準。

同一實體的曲線等價分組仍可能漏合併，方向也依賴 Manhattan 與模型地板假設；因此即使
方向檢查通過，狀態仍為 `conditional_candidate`，不代表已驗證的無人 commissioning。
沒有尺度來源，`height_m=null`、`scale_status=unknown`；內部借用校正器所需的單位高度
不輸出為公尺量測，也不產生可部署的 camera.json。

## 驗證範圍

測試包含已知幾何下的焦距／姿態／畸變恢復、留出座標與語意污染不影響擬合、
錯誤地板標籤拒絕、同一條線的分離片段保持同側、不同平行邊保留區別、弱邊緣原像素定位、
遮擋候選排除、來源改變拒絕及原先的結構校正回歸。
最終全套測試 **4,257 passed、12 skipped**，耗時 149.85 秒；跳過項目需要 CUDA。
全專案 Ruff check／format 與新增／修改 Python 檔案的型別檢查通過。
提交前另修正鎖定 NumPy 型別定義要求的明確 `argmin(axis=0)` 呼叫；修正後 29 項相關
測試通過，鎖定依賴的 src 型別檢查維持既有 8 項基線、沒有新增診斷。三台分組及方向
結果已重算並確認數值完全一致；最終程式副本與核對紀錄在 v2 run 的 `compatibility/`。

實際回歸使用高雄、台中、桃興三台既有相機的 18 張原始影格。這些店已參與開發，
只能作回歸，不是陌生店盲測；輸出的候選數、模型分數與幾何檢查都不能換算成現場實測精度。
